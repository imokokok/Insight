## Proposed entry — Oracle / risk intelligence

- **Insight Oracle** — `https://www.oracleinsight.xyz/api/mcp` — remote MCP server for cross-provider oracle comparison, pre-trade price-integrity checks, Oracle Watch, and signed decision evidence. Free discovery supports `initialize`, `tools/list`, and `ping`; metered assessments use the caller's API-key or x402 configuration. [Source](https://github.com/imokokok/Insight) · [Skill](https://github.com/imokokok/Insight/tree/main/skills/insight-pre-trade-safety)

The service is read-only with respect to user funds and never signs or sends a
user transaction.
