# First embedded-distribution targets

This is a qualification list, not outreach already sent. The offer is selected
per buyer: Insight alone, PriorSeal alone, or the combined Guarded Action path.

| Priority | Target surface                        | First offer                               | Why this fits                                                                                  | Required next authority                                                 |
| -------- | ------------------------------------- | ----------------------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 1        | Coinbase Wallet MCP / Base Wallet     | combined Guarded Action developer preview | Existing direct Base EOA skill aligns with the first profile.                                  | Wallet MCP integration review and any host-specific terms/allowlisting. |
| 2        | Aave V3 Base integrators              | combined path                             | Exact Aave supply/borrow call makes risk, authority and receipt boundaries testable.           | One integrator chooses a user flow and test cohort.                     |
| 3        | Base AgentKit/CDP builders            | Insight Skill first, then combined path   | Agent builders need an installable risk decision before write tools.                           | Builder or platform owner agrees an integration point.                  |
| 4        | PriorSeal SDK adopters                | PriorSeal receipt module                  | Lowest-friction path: add Guarded Action state and evidence without changing their risk layer. | Developer selects executor and evidence consumer.                       |
| 5        | SendAI skills ecosystem               | Insight Skill                             | Oracle-category Skill is directly discoverable to Solana Agent builders.                       | Maintainer accepts the prepared PR.                                     |
| 6        | Solana AI infrastructure directories  | Insight Skill                             | Existing read-only MCP and x402 discovery assets can reach agent developers.                   | Maintainer accepts the prepared entries.                                |
| 7        | BNB Agent SDK builders                | Insight risk decision                     | Agent identity/commerce runtime can embed decision-input integrity before an action.           | Runtime owner confirms adapter and payment semantics.                   |
| 8        | Olas service creators                 | Insight or PriorSeal independently        | Autonomous service operators need bounded input checks or portable execution evidence.         | Service owner selects one repeatable operation.                         |
| 9        | x402 facilitator/discovery ecosystems | Insight pay-per-call discovery            | Useful only after a compatible facilitator and public resource listing are verified.           | Account holder approves terms and any SIWX/payment action.              |
| 10       | DeFi treasury automation teams        | PriorSeal first or combined path          | Auditable bounded authority is clearer than a general “agent trading” pitch.                   | Treasury owner selects a non-custodial pilot path.                      |

Start with priorities 1–3. A target is qualified only after it has a named user
flow, exact executor, evidence consumer, and confirmation that the profile is
not a generic transaction abstraction hidden behind a swap or batch interface.
